# رفد | Rafd

**لإدارة المساعدات وتنظيمها**

إصدار 1.0.2: نظام عام لتوزيع المساعدات وفق دورة مستقلة لكل نوع من العطايا، مع استحقاق اختياري بحسب أفراد الأسرة. يدعم الكميات المعدودة؛ ليس نظامًا ماليًا أو لإدارة المخزون.

تجربة حارة الروضة، تريم. أندرويد وقاعدة SQLite محلية مشفرة، جوال أم وموزعون، ومزامنة محلية، صلاحيات مركزية، نسخ احتياطي مشفرة واستيراد Excel. يلزم اختبار ميداني ببيانات وهمية قبل التشغيل الحقيقي.

معرّف أندرويد `ye.gaz.distribution` والمفاتيح والبروتوكول وأسماء القاعدة الداخلية ثابتة لتوافق التحديثات والنسخ القديمة. اسم المستودع المستهدف `Rafd`؛ تتطلب إعادة تسميته صلاحية إدارية على GitHub.
