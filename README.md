# رفد | Rafd

**لإدارة المساعدات وتنظيمها**

إصدار 1.0.18: نظام عام لتوزيع المساعدات وفق دورة مستقلة لكل نوع من العطايا، مع استحقاق اختياري بحسب أفراد الأسرة. يدعم تحديد إجمالي عطايا كل حقيبة وحد التنبيه قبل نفادها، ويخفف ازدحام أدوات المسجلين والكشوف مع تسريع تخزين قاعدة البيانات المشفرة عبر ذاكرة مؤقتة محلية آمنة. ليس نظامًا ماليًا أو نظام جرد شاملًا.

تجربة حارة الروضة، تريم. أندرويد وقاعدة SQLite محلية مشفرة، جوال أم وموزعون، ومزامنة محلية، صلاحيات مركزية، نسخ احتياطي مشفرة واستيراد Excel حتى 1000 سجل، وعرض الواجهات حسب الطلب دون تحديث الكشوف المخفية، مع تحسين البحث والتوزيع عند وجود مئات السجلات. يلزم اختبار ميداني ببيانات وهمية قبل التشغيل الحقيقي.

معرّف أندرويد `ye.gaz.distribution` والمفاتيح والبروتوكول وأسماء القاعدة الداخلية ثابتة لتوافق التحديثات والنسخ القديمة. اسم المستودع المستهدف `Rafd`؛ تتطلب إعادة تسميته صلاحية إدارية على GitHub.
