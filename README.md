# توزيع الغاز | Gaz Distribution

مشروع أندرويد مستقل لتوزيع الغاز، يبدأ بتجربة حارة الروضة – تريم، ويصلح للتعميم على الحارات.

## المواصفات المعتمدة
- APK موحد، وقاعدة SQLite محلية مستقلة لكل حارة؛ لا Firebase ولا Cloudflare ولا حاسوب لإدارة التوزيع.
- جوال أم لدى المسؤول، وجوالات موزعين بصلاحيات مستقلة، وربط آمن ومزامنة محلية أو عبر الإنترنت، مع استمرار العمل دون اتصال.
- تخصيص حصص المستفيدين للموزعين لمنع ازدواجية الصرف دون اتصال، ثم مزامنة العمليات بمعرّفات فريدة.
- نسخ احتياطي مشفر واستعادة ونقل الجوال الأم بإجراء مضبوط.
- GitHub مخصص للمصدر وبناء APK فقط، وليس لتخزين بيانات الأهالي.

## الحالة
تأسيس جديد بعد تعذر استرجاع الأرشيف الأولي. الإصدار 0.1.0 قيد التطوير؛ لا يعتمد للتوزيع الحقيقي قبل اختبار المزامنة والحماية والاستعادة على جهازين.
