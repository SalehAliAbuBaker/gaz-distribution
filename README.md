# توزيع الغاز | Gaz Distribution

مشروع أندرويد مستقل – تجربة حارة الروضة، تريم، وقابل للتعميم.

الإصدار 0.1.0: نموذج محلي أحادي الجهاز بقاعدة SQLite، تسجيل الأسر ودورات التوزيع والتسليم وسجل الإحصائيات، مع قيد منع تكرار التسليم للأسرة في الدورة نفسها. لا تستخدم بيانات حقيقية قبل استكمال الإقران والمزامنة والتشفير والنسخ الاحتياطي والاختبارات.

المواصفات: APK موحد، قاعدة مستقلة لكل حارة وجوال أم وجوالات موزعين، عمل دون اتصال، مزامنة عبر Wi-Fi أو الإنترنت، وتخصيص حصص حصري. لا Firebase ولا Cloudflare ولا حاسوب للإدارة. GitHub للمصدر والبناء فقط. راجع docs/next-steps.md.

بناء APK التجريبي عبر GitHub Actions. إعادة تأسيس مستقلة بعد تعذر استعادة الأرشيف الأولي. لم يختبر APK على جهاز حقيقي بعد.
