# المرحلة الثانية — أساس أندرويد 0.2.0 (اختبار جهاز واحد)
- تضمين واجهة الويب المعتمدة 0.1.6 وأصولها المحلية كما هي، من مجلد docs، عبر WebViewAssetLoader. لا صلاحية إنترنت في APK في هذه المرحلة.
- قاعدة SQLite جديدة منفصلة عن النموذج الأصلي: سجلات منفصلة مشفرة AES-GCM بمفتاح Android Keystore؛ تحديث السجلات المتغيرة داخل معاملة واحدة، تحقق من المعرفات ورقم الأسرة وتكرار التسليم والمراجع. لا حصص يومية، لكن الاختبار الحالي يستخدم قراءة الحالة كاملة وحدًا وقائيًا لحجم ملف النسخة 64 MiB؛ يلزم اختبار الحجم والسرعة.
- هوية تثبيت مستقلة، وdeploymentId محلي عند إنشاء المنظومة. لم تُربط الأجهزة بعد.
- ملف احتياطي محمول مشفر بكلمة مرور مستقلة (PBKDF2-HMAC-SHA256، 310000 دورة، salt عشوائي، AES-GCM). اختيار مكان الحفظ أو ملف الاستعادة بأداة أندرويد. الاستعادة تتحقق من البنية ثم تطلب موافقة الاستبدال.
- طباعة PDF عبر PrintManager، مشاركة الملف عبر FileProvider، حفظ PDF/CSV عبر واجهة اختيار الملفات.
- صيغة قاعدة النموذج القديم GasDb ليست مهاجرة؛ لا تستخدم النسخة الاختبارية القديمة مع بيانات حقيقية. لا نقل تلقائي من المتصفح. الأدوار الحالية داخل واجهة محلية فقط وليست صلاحيات شبكية.
- سير البناء: أضيف إعداد Android SDK الرسمي قبل البناء. لا توقيع إصدار نهائي؛ artifact debug لا يعتمد للتحديثات الدائمة. 
- المتبقي الإقران المشفر QR، تفويض التخصيص من الجوال الأم، مزامنة سجل عمليات idempotent، وضع LAN واتصال عن بعد، التوقيع الثابت، واختبارات فعلية وتعدد الأجهزة والاستعادة. ممنوع التشغيل الحقيقي قبل نجاحها.
