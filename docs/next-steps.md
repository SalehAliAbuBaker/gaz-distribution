# شروط الانتقال إلى الاختبار الثنائي
النسخة المحلية الحالية ليست صالحة لبيانات حقيقية. قبل أي تشغيل ميداني:
1. هوية الحارة والجهاز بمفاتيح Android Keystore، وإقران مصادق عليه عبر QR.
2. سلطة واحدة لتخصيص أسرة/دورة لجهاز معين؛ حظر نقل التخصيص حتى يتأكد تسليم الجهاز القديم أو إبطال دورة التوزيع وضبط التسوية. لا يجوز السماح لنفس الأسرة على جهازين مستقلين دون اتصال.
3. سجل عمليات ب UUID وإعادة إرسال آمنة ومؤشر مزامنة؛ ارتباط بالحارة والجهاز والدورة والتحقق من الصلاحيات عند استلام كل عملية.
4. نقل مشفر عبر LAN وVPN أو وسيط اتصال دون حفظ قاعدة البيانات على خادم، والتحقق من قيود أندرويد على التشغيل في الخلفية.
5. نسخ احتياطي مشفر واختبار الاستعادة ونقل صلاحية الجوال الأم دون ازدواج السلطة.
6. تسجيل الصلاحيات والمراجعة والتسويات، وتوقيع APK ثابت لكل تحديث قبل اعتماد نسخة رسمية.
