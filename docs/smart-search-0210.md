# 0.2.10
شريط البحث في الرئيسية قبل الأزرار. بحث محلي فوري بالاسم والرقم والمنزل والمربع، والهاتف والمنطقة للأم. تطبيع الهمزات والتشكيل والتاء المربوطة والأرقام العربية والفارسية، يسمح بالبحث بكلمات متفرقة وعرض أول 15 نتيجة. النقر يفتح بيانات المستفيد مع حالة آخر ثماني دورات، وتعديل البيانات حسب الصلاحية. الموزع: النتائج تخص التخصيصات المحلية فقط، بموافقة الاطلاع أو التسليم؛ لا تظهر معلومات الأسر الأخرى، والتحقق من الصلاحيات عند جلب النتائج وعند فتحها أو تسجيل التسليم. حقل البحث يفرغ عند الاختيار والانتقال. لا تغيير لبيانات الاقتران.
