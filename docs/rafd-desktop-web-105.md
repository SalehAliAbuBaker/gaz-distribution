# رفد 1.0.5 على الكمبيوتر
تم نشر نفس واجهة رفد 1.0.5 عبر GitHub Pages. قارئ باركود Code39 في المتصفح يستخدم BarcodeDetector وgetUserMedia على HTTPS في المتصفحات الداعمة، وإدخال الكود اليدوي وقارئ USB بديلان. إيقاف الكاميرا عند الإغلاق أو تغيير الواجهة أو إخفاء التبويب. المتصفح يخزن السجلات محليًا ولا يتصل تلقائيًا بقاعدة أندرويد ولا يشارك تراخيص أندرويد؛ لا ينبغي تقديمهما على أنهما متزامنان. الإصدار النصي 1.0.5؛ تعديل خاص بقدرات المتصفح.
