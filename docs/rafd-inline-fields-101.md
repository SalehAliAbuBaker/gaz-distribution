# رفد 1.0.1
عناوين الحقول داخل حدودها؛ عند الملء أو التركيز تصبح صغيرة في أعلى الحقل. للتاريخ والقوائم والأرقام التلقائية عنوان داخلي دائم. الاحتفاظ بالأسماء والقيم والصلاحيات والاقتراحات الذكية. التغيير للشاشة لا للمستندات. خيارات التحديد والمفاتيح تبقى واضحة. نافذتا كمية التسليم وعنوان الربط الأصليتان تستخدمان تلميحات داخل الحقول. يلزم اختبار فعلي على الهاتف.
