# 0.2.12
تخصيص جماعي بجميع المستفيدين المتاحين أو حسب المربع مع عدد كل مجموعة وإمكانية استثناء أفراد. بطاقة المستفيد من السجل والبحث؛ تقسيم العنوان والتواصل وبيانات الأسرة وحالات جميع الدورات، نموذج إضافة وتعديل مطوي افتراضيًا. بطاقة الموزع تعرض البيانات المتاحة له وحالة التسليم دون توسيع الصلاحيات. لا تغيير للبيانات أو الاقتران. يلزم اختبار فعلي.
