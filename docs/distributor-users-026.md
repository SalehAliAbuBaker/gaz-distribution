# 0.2.6 — واجهة الموزع وصلاحياته
ست بطاقات مباشرة للموزع: الأسر المخصصة، تسجيل التوزيع، سجل التسليم، الكشوف والتقارير، المزامنة، الإعدادات. من الإعدادات يستطيع مدير الجوال الموزع إدارة حسابات محلية وصلاحيات منفصلة، وتسجيل الدخول الأصلي يظل صالحًا. الأذونات تتحقق عند تنفيذ الوظيفة الأصلية؛ الموزع لا يعدل الأسر أو الدورات أو التخصيصات أو الحركات الموقعة. الحركات الجديدة تتضمن هوية المستخدم المنفذ وتُنقل إلى الأم. الحركات القديمة تبقى باسم الجهاز. الكشوف التجريبية ملخصات حسب الدورة ومشاركة نصية؛ إدارة الحسابات مركزيا من الأم، استرداد السلطة، وPDF/طباعة الموزع ليست ضمن هذا الإصدار. حدّث الجوالين دون الحذف؛ اختبار الأجهزة الفعلي مطلوب.
