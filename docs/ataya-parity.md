# معاينة 0.1.3 — نقل وظائف عطايا

المرجع: https://github.com/SalehAliAbuBaker/ataya/blob/main/index.html

تسجيل وتعديل وحذف الأسر والدورات والحركات، تحديد جماعي، تصنيف وبحث، كشف على نمط عطايا وتوقيعان، طباعة A4، مشاركة ونسخ النص وCSV. صلاحيات محلية تجريبية منفصلة (اطلاع، إضافة، تعديل، حذف، تقارير، إدارة)، مع رموز مرور مشتقة محليًا. لا اتصال بقاعدة عطايا، لا نقل لبياناتها أو حساباتها. تبقى بيانات معاينة الغاز في مفتاح التخزين السابق. الحذف مرتبط بتأكيد ودورة مفتوحة.

غير مكتمل: PDF مباشر كمرفق، Excel أصلي، إدارة حقول ديناميكية، نسخ احتياطي آمن، مزامنة الهاتف الأم، حماية صلاحيات حقيقية خارج المتصفح، Android APK. اختبار تركيبي فقط؛ يجب اختباره عمليًا على الجوال قبل استخدام بيانات حقيقية.
