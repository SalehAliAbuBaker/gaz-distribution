# صيغة النسخ الاحتياطية في 0.2.3
- اسم ملف التصدير gaz_backup_<timestamp>_<id>.json.gz ونوع application/gzip.
- ملف GZIP حقيقي يحتوي JSON لغلاف ذي إصدار 2؛ البيانات نفسها JSON مضغوطة قبل تشفير AES-256-GCM، وتخزن داخل الغلاف بترميز Base64. لا توجد أسماء أو هواتف أسر أو بيانات دخول قابلة للقراءة بمجرد فك الضغط. يلزم رمز النسخة لفك التشفير.
- الاستعادة تتعرف إلى محتوى الملف، لا امتداده، وتقرأ أيضًا GAZB1 من ملفات .gazbak القديمة؛ تحقق من التشفير وصحة بنية السجل قبل استبدال البيانات. لا تدعم استيراد JSON غير مشفر أو ملفات تطبيقات أخرى.
- حد لحجم الملف وللبيانات بعد فك الضغط لمنع التضخم. لا يلغي الضغط الحاجة إلى النسخة الخارجية وكلمة مرورها.
- نسخ البيانات لا تستعيد سلطة الاقتران/مفاتيح الجهاز؛ الاستعادة تظل مقيدة بالجهاز المستقل حتى استكمال استرداد السلطة. لا تحذف جهازًا مقترنًا.
- اختبارات JVM تشمل البنية، العربية، الحجم على عينة متكررة مصطنعة، النسخ القديمة، خطأ كلمة المرور والعبث وحد فك الضغط. لا توجد قياسات لبيانات الحارة الحقيقية.
