# 0.2.16
نسبة الاحتياج اختيارية نصية أو رقم حتى 200 حرف، نموذج XLSX يقبل النص والأرقام والفراغ. ترتيب القيم الرقمية تنازليًا ثم النصوص أبجديًا ثم الفراغ. اقتراحات محلية في حقول رابط الأسرة والمربع والمنطقة والاحتياج والتصنيفات والملاحظات ومسمى الدورة والمورد والتفاصيل؛ تُختار مباشرة ويقبل الحقل قيمة جديدة. القوائم تعرض 30 سجلًا لكل صفحة في سجل المستفيدين والتوزيع للأم وفي الأسر والتسليم للموزع. البحث يشمل كامل المجموعة، التحديد الجماعي للتوزيع يشمل جميع النتائج المطابقة لا الصفحة وحدها. شاشات التخصيص والتقارير لم تغير آلياتها. تجريبي؛ يلزم اختبار ميداني.
