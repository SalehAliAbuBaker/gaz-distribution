# 0.2.11
تخصيص الأسر جماعيًا: تحديد الكل المتاح، التصفية حسب مربع كامل أو البحث، تحديد وإلغاء الظاهر، إلغاء جميع التحديدات، وإبقاء الاختيارات بين المرشحات مع عداد ظاهر. لا تظهر الأسر المخصصة أو المستلمة في الدورة. تأكيد العدد والموزع والدورة قبل حفظ الدفعة داخل معاملة واحدة. لا تغيير لبروتوكول المزامنة أو هوية الاقتران. التحديث التجريبي يتطلب اختبارًا على الجوال.
