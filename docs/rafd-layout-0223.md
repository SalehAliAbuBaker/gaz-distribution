# رفد 0.2.23 — تنسيق الواجهات
- رأس مدمج وشريط مستخدم في صف واحد بأيقونات البصمة والمظهر والخروج، ملخص الإحصاءات فوق شبكة رئيسية بأحجام موحدة، وعدد أعمدة متجاوب.
- ترويسة موحدة للواجهات؛ حقول وأزرار وفلاتر متناسقة ومسافات أقل، صفوف معاملات واضحة ومعاينة كشف وشريط سفلي محسّن بحجز مساحته الفعلية.
- تنسيق خاص للشاشة فقط؛ لا تغيير لقياسات الورقة أو قواعد الصرف أو البيانات أو الصلاحيات. تنسيق أساسي لنوافذ الاقتران الأصلية؛ لا نقل الثيم إلى Android الأصلي.
- يلزم اختبار فعلي على الجوال بعد البناء.
