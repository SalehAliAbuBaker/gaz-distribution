# رفد 0.2.18
تغيير اسم العرض والترويسات والحقوق والتواصل وملفات التصدير الجديدة واسم Gradle وأسماء حزم الإصدار والشعار المتجهي إلى صندوق عطاء وقلب بالألوان المعتمدة. لا تغيير لمعرّف التطبيق أو قاعدة البيانات أو التوقيع أو أسماء الحقول الداخلية أو بروتوكول الاقتران. الكشوف المرتبطة بالغاز تبقى معنونة بحسب محتواها. لا تنفيذ للسلال والنقد بعد. إعادة تسمية المستودع من إعداداته الإدارية. اختبار التحديث الميداني مطلوب.
