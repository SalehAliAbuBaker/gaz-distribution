# تصاريح رفد 1.0.1
تعيين وتغيير كلمة المرور محليًا بعد فتح المفتاح المشفر، مع تشفير AES-GCM واشتقاق PBKDF2 وحفظ ذري. المفتاح العمومي ثابت. عند بناء نسخة المالك الخاصة فقط يضاف ملف المفتاح المشفر إلى assets/owner/permit-key.json خارج GitHub ثم يُوقّع APK. لا يُضمّن مفتاح أو كلمة مرور في المستودع أو ملفات البناء العامة. في التثبيت الأول تُستخدم كلمة المرور السابقة لفتح المفتاح المضمّن مرة واحدة ثم يطلب اختيار كلمة مرور جديدة. عند تحديث تثبيت قائم يتقدم الملف المحفوظ داخليًا على المفتاح المضمّن. لا تنشر نسخة المالك؛ حذف التطبيق يعيد التهيئة باستخدام المفتاح الأصلي المضمّن. لا يتغير توقيع التصاريح السابقة.
