# رفد 1.0.3 — تصريح تشغيل أندرويد
- شاشة تفعيل أصلية قبل فتح WebView، رمز خاص بالجهاز مشتق من Android ID (مرتبط بالتوقيع/المستخدم/الجهاز)، تحقق RSA/SHA-256 دون اتصال. لا يوجد مفتاح خاص في المستودع.
- تصاريح الأم والموزع، مؤقتة أو دائمة، منفصلة عن الاقتران. حفظ التصريح في تفضيلات التطبيق، يبقى عند التحديث بنفس التوقيع. فحص عند الفتح والعودة وكل 30 ثانية أثناء العرض. انتهاء التصريح يقفل الواجهة ولا يمسح السجلات. تاريخ الجهاز محلي؛ مقاومة إرجاع الساعة محدودة، ولا إلغاء فوري عن بعد. إعادة ضبط المصنع أو تغيير التوقيع قد يغير المعرّف.
- لوحة الإصدار الخاصة بالمطور ملف HTML محلي ومفتاح مشفر مستقل. المالك مسؤول عن حفظ المفتاح وكلمة المرور منفصلين. معاينة المتصفح العامة ليست تطبيق أندرويد ولا تُستخدم للسجلات الحقيقية. لا تدّعي الحماية ضد جهاز معدل/root أو نسخة معدلة من البرنامج. اختبار بناء وتفعيل ميداني مطلوب.
