# 0.2.13
مدير الأم يصحح أو يحذف أو يعيد إضافة تسليم مرتبط بتخصيص تمت تسويته، مع سبب وسجل رقابي والإيصال الموقع الأصلي محفوظ. الأسرة المخصصة غير المسلمة تحتاج استرداد الصلاحية: المزامنة الأولى تقفل التسليم على الموزع، والثانية تؤكد القفل بعد إرسال أي إيصال متأخر. لا يمكن تسليمها من الأم قبل ذلك. لا يُعاد تخصيص المنحة لموزع آخر في هذا الإصدار. الدورة المغلقة تحتاج إعادة فتح. تحديث جميع الأجهزة مطلوب لعرض التصحيحات والاسترداد. النسخ تحوي سجل التصحيح لكن الاستعادة تبقى محمية.
