# رفد 0.2.22
- تعميم مسميات الكمية والكشوف والشير والتوزيع لجميع المساعدات المعدودة، مع بقاء معرفات الملفات والقاعدة الداخلية.
- حد اختياري للعطيتين وحد اختياري للثلاث، كلاهما أكثر من (لا يشمل الحد). أساس 1 عند التفعيل، وأولوية الدرجة الأعلى. بدون حدود يبقى استحقاق الدورة القديم. التوزيع الفردي والجماعي والتخصيص الموقّع يراعي القاعدة؛ التخصيص السابق لا يتغير والحركات السابقة تبقى.
- رجوع أندرويد من الشاشة إلى الرئيسية، ومنها أو شاشة الدخول تأكيد الخروج ثم إغلاق المهمة. المتصفح يدعم تحذير الرجوع الداخلي بحسب إمكاناته؛ إيماءة Home أو Recent Apps في النظام لا يمكن اعتراضها.
- يلزم اختبار البناء والتجربة الميدانية، ولا يعد تعميم المسميات نظامًا ماليًا أو للمخزون.
