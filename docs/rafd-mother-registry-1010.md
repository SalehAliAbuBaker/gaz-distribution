# رفد 1.0.10 — صلاحيات إدارة المسجلين في الجهاز الأم

- مدير الجهاز الأم، بالحساب صاحب الصلاحية الإدارية، يستطيع تعديل جميع بيانات المسجلين حتى مع ارتباطهم بتخصيصات موزعين. يبقى رقم المسجل التلقائي ثابتًا لحماية المراجع والمستندات.
- تعديل اسم مسجل مرتبط بتخصيص موقّع لا يُغيّر رمز التخصيص السابق؛ تُرسل بيانات الاسم الجديدة كحقل مصدَّق منفصل عند مزامنة الجهاز الفرعي.
- إضافة زر الحذف إلى صفحة تفاصيل المسجل إضافة إلى أزرار القائمة.
- إذا لم توجد تخصيصات أو حركات تسليم، يجوز حذف المسجل نهائيًا؛ إذا وُجدت أي علاقة تاريخية، ينتقل إلى الأرشيف دون حذف إيصالات موزع أو تاريخ تسليم، ويمكن استعادته من زر «المسجلون المؤرشفون».
- لا يُدرج المؤرشف في البحث وقائمة الطباعة والتسليم أو تخصيصات جديدة. تظهر الحركات السابقة في الكشوف التاريخية للحقيبة.
- التخصيص الذي صدر لجهاز موزع قبل أرشفة المسجل يبقى صالحًا إلى حين استرداد صلاحيته ومزامنة الموزع؛ لا يمكن إلغاؤه تعسفيًا دون تواصل مع الجهاز.
- يُظهر التطبيق خطأ حفظ محددًا بدل رسالة عامة فقط عند اعتراض الحماية المحلية.
- لم تُغيَّر بيانات أو تصاريح أو إيصالات موجودة تلقائيًا. يجب عدم حذف التطبيق قبل التحديث.
