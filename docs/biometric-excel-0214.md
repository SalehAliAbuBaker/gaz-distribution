# 0.2.14
دخول بيومتري محلي لحساب واحد في الجهاز بعد التحقق من كلمة المرور وتأكيد بصمة Android القوية (Android 9 فأحدث). المفتاح مرتبط بالمصادقة ولا تُخزن كلمة المرور. تغيير بيانات الحساب أو إصدار سياسة الموزع يتطلب إعادة التفعيل. شاشة المستفيدين لمدير الأم: تصدير XLSX، استيراد حتى 100 اسم، معاينة، رفض الدفعة كاملة عند وجود تكرار أو نقص البيانات، ترقيم تلقائي. لا تُعدل سجلات سابقة. الاسم ورقم المنزل وعدد الأفراد إلزامية. إدخال نسبة الاحتياج كعدد 0–100 لا كنسبة Excel. اختبار ميداني مطلوب.
